# Super Mario Galaxy
## 📌 Sobre o Projeto

Este projeto foi desenvolvido inspirado no universo de Super Mario Galaxy, trazendo uma landing page temática com foco em animações, design moderno e interatividade.

O objetivo foi praticar conceitos de front-end e criar uma experiência visual dinâmica para os usuários.

---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

---

## 🎯 Funcionalidades

- Layout responsivo
- Animações e efeitos visuais
- Interface interativa
- Design inspirado no universo gamer

---

## 📱 Responsividade

O projeto foi desenvolvido para funcionar em:

- 📱 Smartphones
- 💻 Desktop
- 📲 Tablets
